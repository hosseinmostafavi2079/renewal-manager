# سیستم مدیریت و یادآوری تمدیدها - فاز ۱

این پروژه ساختار اولیه کانتینرهای داکر و دیتابیس پایدار PostgreSQL را برای سیستم تمدیدها فراهم می‌کند.

## راهنمای راه‌اندازی و اجرای لوکال

### گام اول: ساخت ساختار فایل‌ها
مطمئن شوید فایل‌ها را دقیقاً با ساختار زیر ایجاد کرده‌اید:
- `backend/requirements.txt`
- `backend/Dockerfile`
- `docker-compose.yml`

### گام دوم: ساخت پروژه اولیه جنگو
از آنجایی که ما پوشه `backend` را به کانتینر مپ (Volume) کرده‌ایم، با دستور زیر کانتینر موقتی ساخته می‌شود تا ساختار اولیه جنگو را مستقیماً درون پوشه `backend` سیستم شما تولید کند:
